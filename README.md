# 國二英文全方位互動特訓基地 (Grade 8 Comprehensive English Hub)

針對 **國中英文 4 大核心必考文法** 精心設計的單頁互動講義網頁：
1. **天氣問答 (Weather)**：`How's the weather?` vs `What's the weather like?`、形容詞/動詞/不可數名詞辨析。
2. **從屬連接詞 (Adverb Clauses)**：`Before`、`After`、`When` 動作先後物理時間軸、逗號黃金法則。
3. **授與動詞 (Dative Verbs)**：雙受詞轉換、`TO` (方向性) vs `FOR` (花心力準備)、代名詞受詞順序。
4. **所有格與所有格代名詞 (Possessives)**：`my pen = mine`、`a friend of mine`、`its vs it's` 陷阱。
5. **段考綜合大魔王測驗**：跨單元混合即時挑戰與計分。

本專案可以直接搭配 GitHub Actions 發布到 GitHub Pages：
