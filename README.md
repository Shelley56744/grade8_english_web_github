# 國二英文互動特訓基地 (Grade 8 English Interactive Handout)

專為 **翰林版國二英語 Unit 1（所有格代名詞）與 Unit 2（時間連接詞 Before / After / When）** 量身打造的單頁互動講義網頁。

## 🌟 特色亮點

- **迷因暖身區 (When... Meme Generator)**：利用貼近國中生日常的表情包與情境，自然融入 `When` 句型練習。
- **失物招領法庭 (Lost & Found Court)**：透過直覺的物歸原主互動題，強化 `mine, yours, his, hers, ours, theirs` 的觀念，破除名詞重複盲點。
- **時間軸倒帶模擬器 (Timeline Rewind)**：視覺化呈現前後動作先後順序，高亮「句首必須打逗號、句中絕不加逗號」的文法規則。
- **段考魔王陷阱庫 (Exam Traps)**：收錄 `Its vs It's`、雙重所有格等歷屆高頻易錯題型。
- **零外部依賴、純單檔運行**：支援 Web Audio 輕量音效與 SpeechSynthesis 英文發音。

## 🚀 如何上架到 GitHub Pages (免費且永久有效)

你可以直接把這個專案推送到 GitHub 並開啟 GitHub Pages：

### 步驟 1：建立 GitHub 儲存庫 (Repository)
1. 登入 [GitHub](https://github.com/)。
2. 點擊右上角 **「+」** $ightarrow$ **「New repository」**。
3. 命名 Repository（例如：`grade8-english-hub`），選擇 **Public**（公開），點擊 **Create repository**。

### 步驟 2：上傳檔案
1. 進入剛建好的 repository 頁面，點選 **「Add file」** $ightarrow$ **「Upload files」**。
2. 將解壓縮出來的 **`index.html`** 與 **`README.md`** 拖曳上傳。
3. 點擊綠色的 **Commit changes**。

### 步驟 3：開啟 GitHub Pages
1. 在該儲存庫上方點選 **「Settings」**（設定）。
2. 在左側欄位找到 **「Pages」**。
3. 在 **Build and deployment** 下方的 **Branch**：
   - 將 `None` 切換為 **`main`**。
   - 資料夾保持 **`/ (root)`**。
   - 點擊 **Save**。
4. 等候約 1~2 分鐘重新整理，上方就會出現綠色的專屬網址：
   `https://<你的帳號>.github.io/grade8-english-hub/`

打開該網址即可直接在電腦、平板或手機上課使用！
